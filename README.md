# Guess-My-Number-Project 🔢

🎯 Guess The Number

Um jogo simples desenvolvido com HTML, CSS e JavaScript, onde o objetivo é adivinhar um número secreto gerado aleatoriamente entre 1 e 20.

🚀 Funcionalidades
Geração aleatória de números.
Sistema de pontuação.
Registro do maior score da sessão.
Feedback visual para números muito altos ou muito baixos.
Reinício da partida sem recarregar a página.
Mudança de cores ao vencer ou perder.

🛠️ Tecnologias Utilizadas
HTML5
CSS3
JavaScript (Vanilla JS)

🎮 Como Jogar
Digite um número entre 1 e 20.
Clique em Check!.
O jogo informará se o número é maior ou menor que o número secreto.
Cada tentativa errada reduz sua pontuação.
Ao acertar, você vence e o recorde é atualizado caso a pontuação seja maior.
📂 Estrutura do Projeto
├── index.html
├── style.css
├── script.js
└── .prettierrc

O jogador recebe dicas para encontrar o número correto e tenta alcançar a maior pontuação possível.
